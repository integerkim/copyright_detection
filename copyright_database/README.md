# copyright_database — 보호(저작권) DB

검사할 영상(`suspect_data/`)을 여기 있는 보호 데이터와 비교합니다.
모달리티마다 폴더가 따로 있고, **파일을 넣기만 하면 다음 실행부터 자동으로 반영**됩니다.
특징 추출 결과는 `cache/db/<모달리티>/`에 저장되며, 파일을 바꾸거나 지우면 다시 계산합니다
(`cache/`는 통째로 지워도 됩니다).

```
copyright_database/
├─ motion/            보호 안무
│   ├─ *.npz            SMPL 모션 (그대로 사용)
│   └─ *.mp4 ...        안무 영상 (첫 실행 때 HybrIK 로 npz 변환, 영상당 수 분)
├─ face/              보호 인물 얼굴
│   └─ <인물>/          그 인물의 영상 또는 사진 (*.mp4 *.jpg *.png, 여러 개 가능)
├─ avatar/            보호 아바타 (전신 외형)
│   └─ <인물>/          그 인물의 전신 영상 (영상 하나 = 카메라 시점 하나)
└─ audio/             보호 음원
    └─ *.mp4 *.wav *.mp3 ...   음원 또는 음악이 들어간 영상
```

## 모달리티별 규칙

| 폴더 | 넣는 것 | 결과에 표시되는 이름 | 비고 |
|---|---|---|---|
| `motion/` | `.npz` (`poses_axis_angle [T,24,3]`, `trans [T,3]`, 30fps) 또는 영상 | 파일명. `곡_파트_번호_퍼포머_...` 형식이면 곡/파트/퍼포머로 나눠 표시 (예: `cupid_chorus_1_KHJ.mp4`) | 하위 폴더 허용. 영상에는 한 사람의 전신이 보여야 함 |
| `face/<인물>/` | 얼굴이 보이는 영상·사진 | 폴더 이름 (`KDG`) | 정면과 측면을 섞어 여러 개 넣으면 좋음 |
| `avatar/<인물>/` | 전신 영상 (5초 정도면 충분) | 폴더 이름 | `config.yaml` 의 `db_view: cam00` 이면 `cam00...` 로 시작하는 시점끼리만 비교. 그런 파일이 없는 인물은 모든 영상과 비교 |
| `audio/` | 음원 또는 음악이 들어간 영상 | 파일명 | 하위 폴더 허용. 보호 음원 수만큼 비교하므로 많을수록 오래 걸림 |

## 현재 들어 있는 데이터

- `motion/`: 안무 250개 (SMPL npz, 기존 motion 모듈 DB)
- `face/`: KDG, SSH, YHS
- `avatar/`: KDG (카메라 5대 × 5초)
- `audio/`: `media1_stage.mp4` (기존 audio 모듈 기준 영상)

같은 사람이라도 얼굴(`face/`)과 아바타(`avatar/`)는 따로 넣어야 합니다. 같은 이름을 쓰면 결과에서
"얼굴과 아바타가 모두 같은 보호 인물을 가리킵니다"처럼 두 판정을 묶어서 설명합니다.
