내가 만들고자 하는 것

비디오가 입력으로 들어갔을 때, 이를 각 모달리티로 분해하고, 이를 각 평가 metric을 통해 평가를 한 후에, 이를 기반으로 저작권이 도용이 되어있는지 여부를 판단하는 것

되어있는 것

각 학생들 별로 모달리티를 할당한 후 이에 대해 입력 비디오에서 모달리티를 추출한 후, 각 모달리티 별 그 모달리티에 대한 도용 탐지를 하는 코드 제작

4가지 모달리티로 되어있음 

내가 원하는 것

각 모달리티를 통합하여, 전체 도용 탐지를 하는 모델 제작, 입력은 비디오, 출력은 도용 탐지 점수와 각각에 대한 세분화된 설명, 설명은 그냥 작은 LLM 모델 하나 써서 이것을 text로 설명해주도록 하기,(ex. 모션쪽 도용이 높으니 도용같다, 전체적으로 점수가 낮으니 도용 아닌 것 같다, 뭐 아바타가 특히 높으니 도용같다, 전체적으로 다 높다 등등...)

이렇게 해서 최종적으로 입력 비디오가 하나 들어가면 출력으로 결과까지 나오는 거 만들기
